# ANDHADHUN
**Arcade for the blind**


## Overview

This project is an **audio-centric, IMU-controlled survival game** designed to be **playable without relying on vision**.  
The player stands at the center of a virtual arena while enemies spawn around them and move inward. Using **head orientation (IMU yaw)**, **spatial audio**, and **haptic feedback**, the player must locate, aim at, and eliminate enemies before they reach and attack.

The game integrates **real-time sensor data**, **3D spatial sound**, and **AI-assisted navigation**, making it suitable for **accessibility-focused gameplay** and **human-computer interaction research**.
